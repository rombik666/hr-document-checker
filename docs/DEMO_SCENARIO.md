# Демонстрационный сценарий

Production-сервис: https://hr-checker.ru

Проект: HR Document Checker — прототип системы проверки HR- и бизнес-документов с использованием rule-based проверок, RAG, персональных FAISS-индексов и LLM-агентов.

## Цель

Показать полный цикл работы: открытие сайта → регистрация/вход → загрузка DOCX → ввод вакансии → генерация отчёта → просмотр отчёта → экспорт DOCX → история → RAG → форма обратной связи.

## 1. Открытие сайта

Откройте `https://hr-checker.ru/web/login`. Проверьте HTTPS, корректный интерфейс, футер и мобильное меню.

## 2. Регистрация

Откройте `https://hr-checker.ru/web/register`, создайте пользователя с ролью `candidate` или `hr`.

## 3. Вход

Откройте `https://hr-checker.ru/web/login`, введите email и пароль.

## 4. Загрузка документа

В личном кабинете загрузите DOCX-резюме. Рекомендуемый текст вакансии:

```text
Требования: Python, FastAPI, PostgreSQL, Docker, Docker Compose, Git, Linux, REST API.
```

Выберите режим `temporary` и запустите проверку.

## 5. Проверка отчёта

Проверьте наличие HTML-отчёта, статуса, сводки, Critical/Major/Minor, evidence-фрагментов, рекомендаций, блока релевантности вакансии и DOCX-экспорта.

## 6. Проверка статусов

| Условие | Ожидаемый статус |
|---|---|
| Замечаний нет | `Готов` |
| Есть только Minor | `Есть замечания` |
| Есть Critical или Major | `Требует доработки` |

## 7. История отчётов

Откройте `https://hr-checker.ru/web/reports`. Проверьте статус, дату с локальным временем, кнопки `Открыть` и `DOCX`.

## 8. RAG для HR

Войдите как HR и откройте `https://hr-checker.ru/web/rag/sources`. Проверьте загрузку источника, включение/отключение, удаление и переиндексацию.

## 9. LLM и RAG API

Проверьте:

```text
https://hr-checker.ru/api/v1/llm/status
https://hr-checker.ru/api/v1/rag/status
```

## 10. Форма обратной связи

В футере нажмите Email, выберите тему, введите описание и отправьте письмо. Проверьте, что в письме есть ID пользователя, email, имя и роль.

## 11. Мобильный интерфейс

Проверьте, что меню открывается слева, кнопка меняется на `Назад`, фон затемняется, элементы кликабельны.
