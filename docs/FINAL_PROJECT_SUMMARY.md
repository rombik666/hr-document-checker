# Итоговое описание проекта

Production-сервис: https://hr-checker.ru

Проект: HR Document Checker — прототип системы проверки HR- и бизнес-документов с использованием rule-based проверок, RAG, персональных FAISS-индексов и LLM-агентов.

## Назначение

Проект реализует прототип системы автоматизированной проверки HR-документов. Система помогает выявлять отсутствующую информацию, слабую структуру документа, проблемы с контактами, размытые формулировки, потенциальные противоречия, расхождения между резюме и вакансией, незакрытые требования вакансии и проблемы, выявленные на основе RAG-контекста.

Система не принимает кадровые решения. Итоговую оценку документа выполняет человек.

## Реализованный функционал

### Web UI

Реализованы страницы входа, регистрации, личного кабинета, проверки документа, истории отчётов, отчёта, RAG-источников, адаптивное мобильное меню, футер с контактами и форма обратной связи через SMTP.

### Пользователи и роли

Роли: `candidate`, `hr`, `admin`.

### Обработка документов

Реализован парсинг DOCX/PDF, извлечение текста, таблиц, секций и сущностей, определение типа документа.

### Агенты

Формальные агенты: `CompletenessAgent`, `ContactValidationAgent`, `SectionStructureAgent`, `DatePresenceAgent`.

Семантические агенты: `TextQualityAgent`, `ContradictionAgent`, `VacancyRelevanceAgent`, `LlmSemanticAgent`.

### RAG

Реализованы загрузка пользовательских RAG-источников, статусы активных и неактивных источников, лимиты хранения, построение персонального FAISS-индекса, ручная переиндексация и использование RAG при проверке документов.

### LLM

Реализованы провайдер-независимый LLM-интерфейс, mock client, Ollama client, OpenAI-compatible client, endpoint статуса LLM, endpoint генерации и LLM semantic agent.

### Отчёты

Отчёт содержит статус, summary, счётчики Critical/Major/Minor, списки замечаний, evidence-фрагменты, рекомендации, релевантность вакансии, закрытые и незакрытые требования, ссылки на HTML и DOCX.

### Статусы

| Условие | Статус | Цвет |
|---|---|---|
| `total_issues = 0` | `Готов` | зелёный |
| есть только Minor | `Есть замечания` | оранжевый |
| есть Critical или Major | `Требует доработки` | красный |

### Инфраструктура

Реализованы Dockerfile, Docker Compose, PostgreSQL, pgAdmin, Prometheus, Grafana, Nginx reverse proxy, HTTPS на домене `hr-checker.ru`, логи, backup/restore и smoke tests.

### SMTP

Форма обратной связи отправляет тему и описание обращения через SMTP Яндекса. В письмо добавляются ID пользователя, email, имя, роль и IP клиента.

### Приватность

Реализованы режим `no_store`, маскирование e-mail и телефонов, отсутствие raw-текста проверяемого документа и исходных файлов в долговременной БД, privacy diagnostics и локальная привязка служебных портов.

## Тестирование

В проекте используются unit, integration, API, web interface, RAG, LLM, privacy, DOCX export, performance и Docker smoke tests. Запуск: `python -m pytest`.

## Ограничения MVP

Система не принимает кадровые решения, интеграция с внешними ATS/HRM не реализована, обучение собственной LLM не выполняется, PDF поддерживается как дополнительный формат, backup/restore реализован на MVP-уровне, админские сервисы доступны через localhost/SSH-туннели.

## Итог

Проект реализует полный цикл проверки HR-документа: от загрузки DOCX/PDF до формирования структурированного отчёта с приоритетами, рекомендациями, RAG-контекстом и DOCX-экспортом. Сервис развёрнут на домене `hr-checker.ru`, работает через Docker и Nginx, использует PostgreSQL, FAISS, LLM-интеграцию, мониторинг и механизмы защиты персональных данных.
