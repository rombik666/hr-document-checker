# Руководство пользователя

Production-сервис: https://hr-checker.ru

Проект: HR Document Checker — прототип системы проверки HR- и бизнес-документов с использованием rule-based проверок, RAG, персональных FAISS-индексов и LLM-агентов.

## Роли пользователей

| Роль | Назначение |
|---|---|
| `candidate` | Загружает документы, запускает проверку, просматривает историю своих отчётов |
| `hr` | Проверяет HR-документы, работает с историей отчётов и персональными RAG-источниками |
| `admin` | Контролирует техническое состояние системы, API, метрики, RAG, LLM и хранилище |

## Регистрация и вход

Регистрация: `https://hr-checker.ru/web/register`.

Вход: `https://hr-checker.ru/web/login`.

После входа пользователь попадает в личный кабинет: `https://hr-checker.ru/web/dashboard`.

## Проверка документа

1. Откройте личный кабинет.
2. Загрузите DOCX или PDF.
3. При необходимости вставьте текст вакансии.
4. Выберите режим хранения.
5. Запустите проверку.
6. Дождитесь формирования отчёта.

DOCX является предпочтительным форматом, потому что лучше сохраняет структуру документа. PDF поддерживается как дополнительный формат, но возможна потеря структуры.

## Режимы хранения

| Режим | Описание |
|---|---|
| `temporary` | Сохраняет санитизированный отчёт и метаданные |
| `metadata_only` | Сохраняет ограниченную информацию об отчёте и метаданных |
| `no_store` | Не сохраняет отчёт в базе данных |

## Отчёт

Отчёт содержит сводку, имя файла, количество замечаний, статус, списки Critical/Major/Minor, evidence-фрагменты, рекомендации, блок релевантности вакансии, закрытые и незакрытые требования, ссылки для открытия отчёта и скачивания DOCX.

## Статусы отчёта

| Состояние | Значение | Цвет |
|---|---|---|
| `Готов` | Замечаний нет | зелёный |
| `Есть замечания` | Найдены только незначительные замечания | оранжевый |
| `Требует доработки` | Найдены критические или значимые замечания | красный |

## История отчётов

История доступна по адресу: `https://hr-checker.ru/web/reports`. На странице можно открыть HTML-отчёт, скачать DOCX и увидеть дату проверки с учётом локального времени пользователя.

## RAG-источники

Страница RAG-источников доступна HR-пользователю: `https://hr-checker.ru/web/rag/sources`. В RAG добавляются только явно загруженные HR-документы. Резюме кандидатов автоматически не попадают в базу знаний.

## Форма обратной связи

В футере сайта есть кнопка Email. При отправке обращения сообщение уходит на почту проекта через SMTP. В письмо добавляются ID пользователя, email, имя и роль, если пользователь авторизован.

## Конфиденциальность

Исходные DOCX/PDF-файлы и raw-текст документа не сохраняются в долговременной БД. E-mail и телефоны маскируются перед сохранением.
